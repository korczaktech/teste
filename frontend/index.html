CONEXÕES KORCZAK

Vincular seus produtos

Nexus, Nexa e Morok ainda não oferecem login federado comum para o Zeus. Você pode autenticar cada produto por sua API oficial; a senha é usada apenas para solicitar o token e não é armazenada pelo Zeus.

N

Korczak Nexus

Vincule a conta usada no Nexus para consultar documentos e pastas.

X

Korczak Nexa

Vincule a conta usada no Nexa para consultar planilhas e modelos.

M

Morok AI

Vincule a conta Morok para consultar memórias, tarefas, arquivos e automações.

Recomendação futura: autenticação única Korczak (SSO) com OAuth/OIDC, para não precisar vincular os produtos separadamente.

ACESSO LOCAL OPCIONAL
Agente do computador
Execute o agente local no computador e cole o token de pareamento. O token fica somente nesta sessão do navegador e é enviado diretamente ao endereço local.
Agente local desconectado.
Nunca cole o token do agente em mensagens para Zeus. Se suspeitar de exposição, remova o arquivo ~/.zeus-agent/token e reinicie o agente para gerar outro.
